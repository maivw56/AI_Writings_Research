# Writing Portfolio

A simple, responsive portfolio site made with plain HTML and CSS—no frameworks or build tools required.

## Personalize it

Open `index.html` and replace:

- `Your Name` with your name
- `you@example.com` with your email address
- The intro and About text with your own words
- The empty note in the Writings section with your writing links

To add a writing entry, copy the commented `<article class="writing">` example in `index.html`, remove the comment markers around it, and replace the title, link, category, year, and description.

## Publish with GitHub Pages

In the repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and the `/ (root)` folder, then save. GitHub will show the published site URL in the Pages settings when it is ready.
